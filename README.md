# Zen Memo (静的ホスト対応・極小WYSIWYGメモ)

「思考を邪魔しない究極の白紙」を追求した、スタンドアロン動作可能な静的Webメモアプリケーション。

## 特徴
1. **画面全体がテキスト領域**:
   - 余計なヘッダーや枠線は一切なし。
   - 先頭の `H1` が自動的にメモのタイトルとして抽出されます。
2. **Markdown ショートカット自動変換（Input Rules）**:
   - `## ` ＋ スペースで見出し2（H2）
   - `### ` ＋ スペースで見出し3（H3）
   - `- ` または `* ` ＋ スペースで箇条書きリスト
   - `1. ` ＋ スペースで番号付きリスト
   - `> ` ＋ スペースで引用ブロック
   - `$$` ＋ スペースで KaTeX 数式ブロック
   - `---` ＋ スペースで水平区切り線
3. **数式（KaTeX）インライン＆ブロックレンダリング**:
   - 挿入された数式はリアルタイムに美しい数式タイポグラフィとしてレンダリング。
   - クリックしてその場で編集可能。
4. **画像最適化（クリップボード貼り付け＆ファイル選択）**:
   - スクリーンショット等をエディタに直接コピペ（`Ctrl+V` / `Cmd+V` / スマホのペースト）可能。
   - Canvas で長辺最大1200pxに自動リサイズ・JPEG/WebP圧縮（品質82%）した上で Base64 化。画像サーバー不要でGist単体で完結。
5. **3つのUIスタイルの動的切り替え**:
   - **案A（カプセル・ピル）**: 中央下部に浮くミニマルなすりガラスピル（展開式）
   - **案B（コーナードック）**: 右下ゴーストFAB ＋ タップでせり上がるボトムシート
   - **案C（全幅ミニマルバー）**: 画面最下部に常駐するキーボード連動型バー
   - `visualViewport` によるスマホソフトウェアキーボード自動追従対応。
6. **ローカルファースト ＋ Gist 明示的同期**:
   - 普段は IndexedDB に自動保存（オフラインでも完全動作）。
   - GitHub PAT（Personal Access Token: `gist` 権限）を設定し、「同期」ボタンを押した時だけ 1つの Gist 内に `<note-id>.md` と `manifest.json` として同期。
7. **CSS カスタマイズ**:
   - 設定画面からカスタム CSS を直接入力でき、フォント・行間・カラーを自由にオーバーライド可能。

## デプロイ方法
ビルドツール（Node.js / npm）は一切不要です。
フォルダごと以下の静的ホスティングにアップロードするだけで即座に稼働します：
- **GitHub Pages**
- **Cloudflare Pages**
- **Vercel / Netlify**
- **S3 / 各種静的ホスティング**
